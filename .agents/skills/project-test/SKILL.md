# 测试

1. 核对候选版本、未提交改动、验收目标和环境。优先用项目已有测试命令、运行器和可控数据。会影响共享服务或真实数据的检查需要对应授权与隔离。
2. 根据范围选择检查。区分单元、模拟集成、真实调用和人工观察。保护既有测试数据。扩大测试范围要有具体风险或验收依据。
3. 记录实际命令、环境、退出状态和每项结果。区分通过、失败、跳过和环境阻塞。失败时给出复现与证据位置，确认报告对应本次候选版本。
4. 将结果交回原任务。测试发现问题时报告可定位的失败。产品修复和测试代码改动按本次任务的授权处理。
